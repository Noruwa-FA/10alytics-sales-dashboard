# 10Alytics Sales Performance Dashboard

**Tools:** Microsoft Excel
**Completed:** November 2025

## Project Overview
Developed a multi-page Excel report tracking sales performance across Nigerian states, product categories, and sales personnel using transactional retail data from 2015-2016.

## What I Did
- Imported and transformed raw sales data in Power Query, creating calculated columns for revenue, profit/loss, and customer age groupings
- Built DAX measures for total revenue by product and state, enabling regional performance comparisons across Accessories, Phones, and Clothing categories
- Designed interactive visuals, including revenue trend lines, state-level maps, and customer demographic breakdowns
- Delivered a clean, filterable dashboard identifying top salespeople, best-performing states, and seasonal revenue patterns

## Key Skills Demonstrated
- Power BI: multi-page reports, DAX, Power Query, calculated columns
- Regional and demographic performance analysis
- Sales trend visualisation and KPI reporting
